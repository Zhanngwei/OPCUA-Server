# HTML 深色流程图对比度修复设计

## 问题与根因

`OPCUA源码学习指南.html` 在 `prefers-color-scheme: dark` 下把 `.diagram` 背景设为 `#172434`，但 `.svgt` 和 `.svgh` 仍使用固定的深色 `#18212f`。背景和文字颜色接近，导致流程图中位于节点外的标签不可读。若只把文字改白，现有白色节点中的文字又会失去对比度。

## 设计

采用主题感知的流程图颜色变量：

- 浅色模式保持当前视觉效果。
- 深色模式使用深色画布、浅色文字和亮蓝灰连线。
- 普通、强调、存储、异常四类节点分别使用深蓝、深青、深棕和深红背景，并使用统一浅色文字。
- 把项目架构图中硬编码的分组背景和说明节点改为可主题切换的 CSS class。
- 使用属性选择器覆盖 SVG 内硬编码的箭头线条和 marker 填色，避免逐条修改所有连线。
- 不改变流程图结构、尺寸、内容、HTML 导航或正文配色。

## 验收标准

- 深色模式的普通文字与流程图画布对比度不低于 4.5:1。
- 深色模式的文字与四类节点填充色对比度不低于 4.5:1。
- 深色模式连线与画布保持清晰可辨。
- 浅色模式现有节点类型与视觉层级不退化。
- HTML 仍有 18 个章节、6 个内嵌 SVG，目录锚点完整，无外部资源依赖。
- 修改仅涉及目标 HTML 和本次设计/计划文档。

## 验证方法

先建立自动化回归检查并确认它在当前 HTML 上失败：检查主题变量、深色覆写以及颜色对比度。完成 CSS/少量 SVG class 修改后再次执行该检查，并复跑 HTML 结构、锚点、重复 ID 和外部依赖检查。
